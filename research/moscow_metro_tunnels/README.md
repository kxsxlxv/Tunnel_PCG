# Moscow Metro tunnel procedural-generation technical base

Research workspace for a high-fidelity procedural geometry model of Moscow Metro running tunnels for Blender/LiDAR simulation.

Status: research in progress.

Planned contents:
- `00_scope_and_method.md` — scope, terminology, source-quality rules
- `01_standards_and_norms.md` — standards, codes, historical/current normative documents
- `02_tunnel_typology.md` — running-tunnel typology by construction method and lining
- `03_geometry_and_dimensions.md` — geometric parameters and cross-sections
- `04_lining_and_joints.md` — cast-iron, precast concrete, monolithic/pressed concrete details
- `05_track_and_clearances.md` — track geometry, gauge, clearances, track bed
- `06_tunnel_equipment.md` — cable brackets, drainage, lighting, signaling-related visible geometry
- `07_photo_reference_catalog.md` — public photographic/diagram references with provenance
- `08_blender_pcg_spec.md` — implementation-oriented procedural model specification
- `data/tunnel_types.json` — machine-readable tunnel archetypes and parameters
- `data/source_register.csv` — source register and confidence

Research date: 2026-09-19.
