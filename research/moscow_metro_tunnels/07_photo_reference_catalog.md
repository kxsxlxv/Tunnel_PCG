# Photo and drawing reference catalog — Stage 1

This catalog stores links and what each reference is useful for. Images are not copied into the repository unless licensing is later verified.

## P01 — Wartime / early cast-iron running tunnel, 0.75 m ring pitch
Source page: https://russos.livejournal.com/1486834.html
Direct image example: https://russos.ru/img/metro/sem/semenovskaya-29.jpg

Useful visual evidence:
- dense cast-iron ribs;
- 0.75 m longitudinal ring pitch characteristic of this documented wartime section;
- cable density and bracket mounting;
- walkway / equipment placement;
- track slab and sleepers;
- signal and wall-mounted equipment.

Source quality: D for dimensions unless corroborated by technical literature; B/C for construction-era visual morphology.
